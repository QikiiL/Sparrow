## 3. 0.x → 1.0.0 安装器（原地升级）

### 3.1 设计

`src-tauri/nsis/installer.nsi`：

- `DetectLegacyInstallDir` 依次读取 `SHCTX` / `HKCU` / `HKLM` 的
  `Software\Microsoft\Windows\CurrentVersion\Uninstall\clipboard` 下 `InstallLocation`。
- 去掉外层引号后，要求目录里存在 `clipboard-manager-tauri.exe` 或 `uninstall.exe`，防止脏注册表带偏安装路径。
- `RestorePreviousInstallLocation`：新 `${MANUPRODUCTKEY}` 优先；没有时才用旧 `InstallLocation`。
- 检测到旧版后设 `$PassiveMode=1` / `$AutoRunApp=1`，目录页、重装页、开始菜单页、完成页跳过；装回旧目录并自动启动。
- 旧版检测不依赖 `%LOCALAPPDATA%`，自定义路径 `D:\clipboard` 可用。

### 3.2 数据与清理

`src-tauri/nsis-hooks.nsh`：

- `KILL_RUNNING_APP` 先精确结束 `clipboard-manager-tauri.exe`，再 `sparrow.exe`，再 `sms-helper.exe`。
- `MIGRATE_LEGACY_USERDATA`：
  - 原地升级（`$INSTDIR == $LegacyInstallDir`）直接跳过，旧 `config/`、`data/` 原样保留；
  - 只有手动改到别的目录时才 `xcopy`，且只在新目录没有对应数据时复制，不覆盖；
  - 失败只 `DetailPrint`，不 Abort。
- `CLEANUP_LEGACY_INSTALL`：
  - 删除旧卸载键（SHCTX/HKCU/HKLM 的 `...\Uninstall\clipboard`）；
  - 删除 `Software\lyz\clipboard`；
  - 删除旧快捷方式 `clipboard.lnk`、`clipboard-manager-tauri.lnk`；
  - 删除 `$INSTDIR\clipboard-manager-tauri.exe`；
  - 双装场景下，若 `$LegacyInstallDir != $INSTDIR`，删除旧目录里的旧 exe / `uninstall.exe`，但保留旧 `config/data`；
  - 删除 `ClipboardManagerAutostart` 计划任务。
- 不自动运行旧卸载器，避免旧卸载钩子把旧数据搬走。

### 3.3 当前验证程度

- 已做：真实注册表只读检测（本机 `D:\clipboard` 被识别）、NSIS 3.11 `-V4` 编译 0 warning、生成脚本静态核对。
- **未做**：真实双击安装器跑一遍覆盖安装（会改本机 `D:\clipboard`、注册表、计划任务，需要 UAC）。如果未来有外部用户，必须补这一步。
- 用户确认目前没有其他下载者，README 已删除「从 0.x 升级」整节；安装器兼容代码保留，方便自用/未来。

## 6. 测试与构建

### 6.1 最新测试基线（2026-10-23 18:49 实测）

| 命令 | 结果 |
|---|---|
| `npx tsc --noEmit` | exit 0 |
| `npx vitest run` | **8 files / 55 tests passed**（3.93s） |
| `cd src-tauri; cargo test --lib` | **90 passed / 0 failed / 4 ignored** |

- 不要跑 `cargo test` 全量：主 bin manifest 是 `requireAdministrator`，测试二进制会 `os error 740`。只能用 `cargo test --lib`。
- `npm run tauri build` 最近一次完整构建在 2026-10-23 01:25，exit 0；此后只改 README/docs，二进制未变。
- 最终发布资产就是 §1.2 的 `sparrow.exe` / `sparrow-setup.exe`。

### 6.2 构建注意

- `vite.config.ts` 的 `build.emptyOutDir = false` 是为规避本机 safe-delete；**每次构建前手动清 `dist`**，否则旧哈希资源会打进包。
- 中文 JSON 用 Python `encoding="utf-8"` 写，不要用 PowerShell 5.1 的 `Set-Content`。
- 先停 `sms-helper.exe` / `sms-capture-helper.exe`，否则 `LNK1104`；不要杀主程序。
- `beforeBuildCommand` 会编译短信助手并复制 `.msix` / `.cer`；三份资源缺失会打包失败。
- 本机 MSVC 在 `D:\Microsoft\VisualStudio`，`.cargo/config.toml` 已固定路径。
